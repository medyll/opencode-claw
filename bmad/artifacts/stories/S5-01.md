# Story S5-01 — Multi-session UI

## Description
Afficher plusieurs sessions actives par projet dans l'interface.

## Acceptance Criteria
- [ ] Liste des sessions actives en header de la TUI
- [ ] Badge avec nombre de sessions (ex: "3 sessions")
- [ ] Clic sur badge → dropdown avec liste des sessions
- [ ] Chaque session montre: titre, statut (active/idle), dernière activité
- [ ] Session actuelle mise en évidence

## Effort
M (Medium)

## Dependencies
Aucune

## Files to modify
- `public/index.html` — dropdown sessions dans tui-header
- `public/app.js` — fonction `renderSessionList(sessions)` + gestion dropdown
- `src/server.ts` — endpoint GET `/api/oc/sessions?projectId=xxx`
