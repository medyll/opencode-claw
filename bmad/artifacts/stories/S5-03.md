# Story S5-03 — Agent priority queue

## Description
File de priorité pour les sessions multi-agents.

## Acceptance Criteria
- [ ] Chaque session a un niveau de priorité (low/normal/high/urgent)
- [ ] API endpoint POST `/api/oc/sessions/:id/priority` pour définir priorité
- [ ] Queue runner traite les sessions high/urgent en premier
- [ ] UI affiche la priorité avec icône (🔴 high, 🟢 normal)
- [ ] Auto-promotion: session sans activité depuis 5min → priorité baisse

## Effort
L (Large)

## Dependencies
Aucune (indépendant)

## Files to modify
- `src/server.ts` — logique de priorité dans queue runner
- `src/data/sessions.json` — ajouter champ `priority` et `lastActivity`
- `public/index.html` — affichage priorité dans session list
- `public/app.js` — update priority UI
