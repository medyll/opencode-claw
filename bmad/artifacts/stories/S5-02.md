# Story S5-02 — Session switcher

## Description
Permettre de basculer entre les sessions d'un projet.

## Acceptance Criteria
- [ ] Clic sur une session dans le dropdown → charge cette session
- [ ] La TUI affiche les messages de la session sélectionnée
- [ ] Le SSE stream se reconnecte sur la nouvelle session
- [ ] Session précédente reste active (peut revenir)
- [ ] Indicator visuel de la session active

## Effort
S (Small)

## Dependencies
S5-01

## Files to modify
- `public/app.js` — fonction `switchSession(sessionId)` + reconnexion SSE
- `public/index.html` — click handlers sur les items du dropdown
