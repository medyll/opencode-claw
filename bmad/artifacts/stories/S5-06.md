# Story S5-06 — Export execution logs

## Description
Télécharger les logs d'exécution en fichier .txt

## Acceptance Criteria
- [ ] Bouton "Export logs" dans info zone (section historique)
- [ ] Télécharge un fichier .txt avec tous les logs de l'exécution
- [ ] Nom du fichier: `{project}-{date}-{time}.txt`
- [ ] Fonctionne pour chaque exécution dans l'historique
- [ ] Format: timestamp + niveau + message

## Effort
S (Small)

## Dependencies
S3-03 (historique doit exister)

## Files to modify
- `public/index.html` — bouton export dans chaque ligne d'historique
- `public/app.js` — fonction `downloadLogs(executionId)` + Blob download
- `src/server.ts` — endpoint GET `/api/executions/:id/logs`
